BRAJESH'S GITHUB PROFILE STARTER
================================

Files included:
- README.md
- assets/header.svg
- assets/developer-animation.svg
- assets/footer.svg
- .github/workflows/snake.yml

BEFORE PUSHING:
1. Create a PUBLIC GitHub repository whose name exactly matches your GitHub username.
2. Extract this ZIP into that repository folder.
3. In README.md, replace every YOUR_GITHUB_USERNAME with your exact GitHub username.
4. Replace YOUR_LINKEDIN_URL with your LinkedIn profile URL, or remove that badge.
5. Add your actual project repository URLs where indicated.
6. Commit and push the files to the main branch.

Commands (run inside the profile repository folder):
git add README.md assets .github/workflows/snake.yml
git commit -m "Build GitHub profile README"
git push origin main

SNAKE:
- Open repository Settings > Actions > General.
- Under Workflow permissions, select "Read and write permissions" if repository policy permits.
- Open Actions tab and run "Generate Contribution Snake" using Run workflow.
- On success, the workflow publishes the SVGs to the output branch automatically.
- Do not create an empty output branch manually unless you need to; the publishing action can create it when permissions allow.
- The gh-pages branch is optional and not needed for this snake workflow.

NOTES:
- The snake SVGs are generated by GitHub Actions; they are not static source SVGs included in this ZIP.
- Third-party stats/typing services may occasionally rate-limit or fail to load.
- Check the Actions log if the snake workflow fails.
